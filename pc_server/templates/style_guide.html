Grid Layouts
module-grid — repeat(auto-fill, minmax(520px, 1fr)) — Module management cards. Cards are at least 520 px wide and fill the available row width.
charts-grid — repeat(auto-fit, minmax(500px, 1fr)) — Chart panels. Uses auto-fit to collapse empty tracks; minimum 500 px.
data-log-grid — repeat(auto-fill, minmax(200px, 1fr)) — Compact key–value pairs inside a panel. Minimum 200 px per column.

New Page Template

Copy this boilerplate to start a new page. It links the shared stylesheet, sets up the standard header, and leaves a placeholder for page content. 

{% raw %}<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page Title — Module Management Server</title>
  <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
  <style>
    /* Page-specific styles only — avoid duplicating shared rules */
  </style>
</head>
<body>

<header>
  <div>
    <h1>🔧 Page Title</h1>
    <div class="header-subtitle">Brief description</div>
  </div>
  <div class="header-actions">
    <button class="btn btn-sm btn-secondary" onclick="window.location.href='{{ url_for('index') }}'>
      ← Dashboard
    </button>
  </div>
</header>

<!-- Optional: controls bar -->
<div class="controls">
  <div>
    <label for="myFilter">Filter:</label>
    <select id="myFilter"></select>
  </div>
  <button class="btn btn-primary">↻ Refresh</button>
</div>

<!-- Page content -->

<script>
  // JavaScript here
</script>

</body>
</html>{% endraw %}

Guidelines: Only add page-specific CSS in the inline <style> block. Never redefine colours, button styles, or layout primitives already in style.css. Use semantic HTML5 elements and keep JavaScript in a single <script> block at the bottom of the body.
