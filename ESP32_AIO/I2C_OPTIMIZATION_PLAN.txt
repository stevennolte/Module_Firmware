// CURRENT ISSUE: I2C Bus Overload
// - WAS reads ADS1115 every 100ms (10 Hz)
// - MainPower reads ADS1115 every 100ms (10 Hz) 
// - myLED updates MCP23017 every 50ms (20 Hz)
// - Total: ~40 I2C transactions/second causing system lag

// SOLUTION OPTIONS:

// Option 1: CENTRALIZED ADS MANAGER (RECOMMENDED)
// Create ADSManager class that reads all channels once per cycle
// and shares data with WAS, MainPower, ESPsteer
// Reduces ADS I2C traffic from 20 Hz to 10 Hz (50% reduction)

// Option 2: REDUCE UPDATE FREQUENCIES
// Change WAS and MainPower to read every 200ms instead of 100ms
// Change myLED to update every 100ms instead of 50ms
// Reduces total I2C traffic by ~60%

// Option 3: STAGGER READ TIMING
// Offset WAS and MainPower read timings by 50ms
// Prevents simultaneous I2C access
// Reduces bus contention without changing frequencies

// Option 4: INCREASE ADS1115 DATA RATE
// Change from default 128 SPS to 250 SPS or 475 SPS
// Reduces I2C transaction time from ~8ms to ~4ms
// Improves bus availability
