Detailed Description

Forward declaration for UDP communication class.

GPS receiver and IMU sensor management class

Provides complete navigation system functionality including:

  • GPS receiver initialization and communication
  • NMEA sentence parsing and data extraction
  • IMU sensor integration for attitude determination
  • Position quality assessment and monitoring
  • Status LED control for fix quality indication

◆ GGA_Handler()

void ESPGPS::GGA_Handler ( )

NMEA GGA sentence handler for GPS position data.

Parses NMEA GGA (Global Positioning System Fix Data) sentences to extract:

  • Fix time (UTC)
  • Latitude and longitude coordinates
  • Fix quality indicator
  • Number of satellites in use
  • Horizontal dilution of precision (HDOP)
  • Altitude above mean sea level
  • Age of differential GPS corrections

Updates the GPS data structure with parsed values for use by navigation and guidance systems.

Note
Called automatically by NMEA parser when GGA sentence is received
See also
VTG_Handler(), parser.h
