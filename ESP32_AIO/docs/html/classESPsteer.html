Forward declaration for UDP communication class.

Precision steering control system class

Manages the complete steering control system including PID control, sensor feedback, motor control, and safety monitoring. Operates in a dedicated FreeRTOS task for real-time performance and provides comprehensive steering functionality for agricultural guidance systems.

void ESPsteer::continuousLoop ( )
private

Continuous steering control loop.

Main steering control loop running in dedicated FreeRTOS task.

Main steering control function that runs continuously in dedicated FreeRTOS task for real-time operation

Continuously processes steering control operations including:

  • Configuration updates and PID parameter adjustments
  • Wheel angle sensor data processing
  • Motor current monitoring for load detection
  • Test state monitoring for manual override
  • Steering control mode selection (test vs automatic)
  • Real-time steering command processing

Runs in a dedicated task with 3ms cycle time for responsive control.

Note
This function runs indefinitely in a FreeRTOS task context
See also
steerLoop(), steerTestLoop(), taskHandler()
