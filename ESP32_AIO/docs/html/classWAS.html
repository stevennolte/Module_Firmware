Detailed Description

Wheel Angle Sensor management class.

Provides comprehensive wheel angle sensing functionality including sensor initialization, continuous measurement, calibration procedures, and support for both wired (ADC) and wireless sensor configurations.

void WAS::loop ( )

Main wheel angle sensor processing loop.

Performs continuous wheel angle measurement including:

  • ADC reading and conversion to angle
  • Sensor filtering and noise reduction
  • Wireless sensor data processing (if enabled)
  • Angle calculation and validation
Note
Should be called regularly for real-time angle feedback
