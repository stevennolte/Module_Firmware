Detailed Description

Singleton class for centralized system data management.

Provides thread-safe access to all system configuration and runtime data. Implements the singleton pattern to ensure consistent data access across all system components. Manages NVS persistence and RTC memory state.

◆ loadConfig()

uint8_t ESPdata::loadConfig ( )

Loads system configuration from NVS storage.

Loads system configuration from NVS storage and initializes runtime data.

Returns
uint8_t Status code (0=success, 1=partial failure, 2=complete failure)

Initializes RTC memory and loads all configuration parameters

Returns
uint8_t Status code (1=success, 0=failure)

Loads all persistent configuration parameters from NVS (Non-Volatile Storage) including network settings, steering calibration, PID gains, and boot state. Initializes RTC memory for power cycle detection and increments boot counter. Prints the loaded configuration to the serial monitor for diagnostics.

  • Loads WiFi IP address and mode
  • Loads steering system calibration and PID parameters
  • Loads GPS and OTA server configuration
  • Handles RTC memory for power cycle and boot count tracking
Note
This function must be called before using any configuration-dependent features.
See also
saveConfig(), initRTCData(), ESPdata.h
