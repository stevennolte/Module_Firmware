bool MCPManager::begin ( ESPdata * espDataPtr,
uint8_t address = 0x20,
TwoWire * wire = &Wire )

Initializes the MCP23017 I/O expander hardware.

Parameters
espDataPtrPointer to ESPdata singleton for configuration access
addressI2C address of the MCP23017 (default 0x20)
wirePointer to TwoWire I2C interface (default &Wire)
Returns
true if initialization successful, false otherwise

Configures the MCP23017 chip including:

  • I2C communication setup
  • GPIO pin direction configuration
  • Input pull-up resistor configuration
  • LED indicator initialization
  • Status indication setup
