Detailed Description

Smart LED status indicator system for system health monitoring.

This header defines the MyLED class which provides comprehensive status indication using a NeoPixel RGB LED including:

  • Color-coded system status indication for error identification
  • Multi-threaded LED animation processing
  • Configurable brightness control
  • Special animation modes for testing and demonstration
  • Real-time system health monitoring and visual feedback

LED status indicator enumeration for system health communication.

Defines color-coded states for comprehensive system status indication:

  • Normal operation indicators (green)
  • Component-specific error indicators (various colors)
  • Special modes for recovery and testing
  • Animation patterns for complex status communication
Enumerator
NO_ERROR 

Green - All systems normal, ready for operation.

Red - Configuration load failed, check NVS.
