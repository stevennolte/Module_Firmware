# ADS Pins (address is 0x48)
* ad0 is Wheel angle sensor High
* ad1 is Wheel angle sensor Low
* ad2 is IS from steer motor driver
* ad3 is Main Power IS

# MCP Pins (address is 0x20)
1. GPA0 work switch ()
2. GPA1 remote switch
3. GPA2 steer switch
4. GPB0 power on indicator
5. GPB1 eth good or wifi good
6. GPB2 gps fix
7. GPB3 rtk fix
8. GPB4 steer in standby
9. GPB5 steer active
10. GPB6 enb for steer module
11. GPB7 ena for steer module
